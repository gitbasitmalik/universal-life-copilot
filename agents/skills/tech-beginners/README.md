# 🖥️ Tech Beginners & Everyday Digital Life

For anyone who wants tech to just work, without the jargon. Fix everyday problems, stay safe from hackers and scams, tame spreadsheets and files, and get better answers from AI tools.

## Skills in this pack

| Skill | What it does | Try saying |
|---|---|---|
| [`tech-support-buddy`](./tech-support-buddy/SKILL.md) | Patient, jargon-free troubleshooting with simple numbered steps that start easy | "My laptop's Wi-Fi keeps disconnecting but my phone is fine" |
| [`security-checkup`](./security-checkup/SKILL.md) | Personal security audit with a prioritised fix-it checklist, never asks for passwords | "Do a security checkup for me, I use the same password everywhere" |
| [`scam-spotter`](./scam-spotter/SKILL.md) | Checks suspicious messages for red flags and tells you exactly what to do | "Is this a scam? I got a text saying my parcel needs a 1.99 redelivery fee" |
| [`spreadsheet-wizard`](./spreadsheet-wizard/SKILL.md) | Writes and explains Excel and Google Sheets formulas from plain English | "In Google Sheets, total column C for each category in column B" |
| [`prompt-polisher`](./prompt-polisher/SKILL.md) | Rebuilds vague prompts into clear ones for AI tools, with before and after | "Improve this prompt: write a post about my bakery" |
| [`digital-declutter`](./digital-declutter/SKILL.md) | Simple folder system, photo cleanup, storage tidy and email rules, safely | "My phone storage is full and I have 12,000 photos. Help me clean up" |

## How to install

Upload any skill folder from this pack (for example `tech-support-buddy/`) using the steps in the [main README](../../../README.md#-how-to-install).
