# 🎬 Content Creators

For YouTubers, newsletter writers, bloggers, storytellers and anyone building an audience. Plan smarter, write faster, and squeeze more out of every piece you create.

## Skills in this pack

| Skill | What it does | Try saying |
|---|---|---|
| [`social-media-planner`](./social-media-planner/SKILL.md) | Content pillars, a posting calendar and ready-to-post captions you can actually sustain | "Plan a month of Instagram and TikTok posts for my home bakery, I have 3 hours a week" |
| [`youtube-script-writer`](./youtube-script-writer/SKILL.md) | Scripts with a 5-second hook, retention beats, B-roll notes and title ideas | "Write a 10-minute YouTube script on budgeting for students, plus title and thumbnail ideas" |
| [`newsletter-writer`](./newsletter-writer/SKILL.md) | Issues with clickable subject lines, a story-led intro and one clear CTA | "Turn these 4 links and my week's update into this Friday's newsletter" |
| [`blog-post-builder`](./blog-post-builder/SKILL.md) | Search-friendly posts from angle and outline to meta description | "Write a blog post on how to start composting in a small flat, with SEO title and meta" |
| [`story-spark`](./story-spark/SKILL.md) | Fiction partner for premises, characters, plot beats, scenes and draft feedback | "My fantasy novel's middle act drags - help me fix the plot" |
| [`content-repurposer`](./content-repurposer/SKILL.md) | Turns one video, podcast or post into threads, carousels, Shorts and more | "Here's my podcast transcript - turn it into a thread, a carousel and two Shorts scripts" |

## How to install

Upload any skill folder from this pack (for example `social-media-planner/`) using the steps in the [main README](../../../README.md#-how-to-install).
