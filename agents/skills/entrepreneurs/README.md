# 🚀 Entrepreneurs, Freelancers & Small Businesses

For founders, side hustlers, freelancers and shop owners who wear every hat at once. These skills help you test ideas, plan the business, win clients, sell more and keep customers happy - without hiring an agency.

## Skills in this pack

| Skill | What it does | Try saying |
|---|---|---|
| [`business-plan-builder`](./business-plan-builder/SKILL.md) | Builds a Lean Canvas with unit economics, break-even and 12-month milestones | "Make a business plan for my mobile dog grooming van" |
| [`startup-idea-validator`](./startup-idea-validator/SKILL.md) | Finds your riskiest assumptions and designs cheap experiments to test them | "Poke holes in my idea for a meal-prep app for shift workers" |
| [`marketing-copywriter`](./marketing-copywriter/SKILL.md) | Writes ads, landing pages and emails with AIDA/PAS, headlines and CTAs | "Write landing page copy for my online bookkeeping course" |
| [`product-description-writer`](./product-description-writer/SKILL.md) | Turns specs into benefit-led, SEO-friendly product listings shoppers trust | "Write a product description for this handmade ceramic mug" |
| [`customer-reply-pro`](./customer-reply-pro/SKILL.md) | Drafts calm, solution-first replies to complaints, refunds and public reviews | "Help me reply to this angry 1-star review about late delivery" |
| [`pitch-deck-outliner`](./pitch-deck-outliner/SKILL.md) | Outlines your deck slide by slide with headlines, visuals and speaker notes | "Outline a 10-slide investor deck for my seed round" |
| [`brand-name-generator`](./brand-name-generator/SKILL.md) | Generates scored name shortlists with taglines and availability checks to run | "Give me name ideas for a calm, premium skincare brand" |
| [`freelance-proposal-pro`](./freelance-proposal-pro/SKILL.md) | Turns a job post into a tailored proposal with scope and tiered pricing | "Write a proposal for this website redesign job post" |

## How to install

Upload any skill folder from this pack (for example `business-plan-builder/`) using the steps in the [main README](../../../README.md#-how-to-install).
