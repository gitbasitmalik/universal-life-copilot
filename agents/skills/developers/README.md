# 💻 Developers & Engineers

For engineers who want a sharp pair-programming partner on demand. These skills explain, debug, review, test and document code, so you ship faster with fewer surprises.

## Skills in this pack

| Skill | What it does | Try saying |
|---|---|---|
| [`code-explainer`](./code-explainer/SKILL.md) | Explains unfamiliar code at your chosen depth, maps flow and flags risks | "Explain what this Python function does, line by line" |
| [`bug-detective`](./bug-detective/SKILL.md) | Turns stack traces into ranked hypotheses, a repro, a fix and prevention | "Why am I getting TypeError: cannot read properties of undefined?" |
| [`code-review-buddy`](./code-review-buddy/SKILL.md) | Severity-tagged review for correctness, security, performance and readability | "Review this diff before I merge it" |
| [`commit-message-writer`](./commit-message-writer/SKILL.md) | Writes Conventional Commits messages and PR descriptions from your diff | "Write a commit message and PR description for this diff" |
| [`readme-generator`](./readme-generator/SKILL.md) | Builds a README that gets strangers installed and running in minutes | "Write a README for my CLI tool from this package.json" |
| [`sql-helper`](./sql-helper/SKILL.md) | Writes, explains and speeds up dialect-correct SQL with index suggestions | "Postgres query for customers with no orders in 90 days" |
| [`regex-builder`](./regex-builder/SKILL.md) | Builds tested, flavour-aware regex with token breakdowns and edge cases | "Regex to match UK postcodes in JavaScript, with tests" |
| [`api-docs-writer`](./api-docs-writer/SKILL.md) | Documents endpoints with examples, error tables and an OpenAPI snippet | "Document this Express route as API reference docs" |
| [`system-design-coach`](./system-design-coach/SKILL.md) | Guides designs with estimates and trade-offs, or runs a mock interview | "Give me a mock system design interview: design a URL shortener" |
| [`test-case-generator`](./test-case-generator/SKILL.md) | Generates runnable tests for edge cases in your framework, with coverage checklist | "Write pytest tests with edge cases for this function" |

## How to install

Upload any skill folder from this pack (for example `code-explainer/`) using the steps in the [main README](../../../README.md#-how-to-install).
